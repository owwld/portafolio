# Portafolio de Actividades y Proyectos - APWE

Este repositorio contiene las actividades y proyectos web desarrollados durante el curso.

---

## 🌐 Enlace a las Páginas Web en Vivo (GitHub Pages)

Para visualizar cualquier actividad o proyecto en vivo desde el navegador, utiliza la siguiente estructura de URL:

**URL Base:**
`https://owwld.github.io/portafolio/`

**Ejemplo de acceso a proyectos:**
Solo añade el nombre exacto de la carpeta al final de la URL base:

- **Actividad 01:** `https://owwld.github.io/portafolio/01%20Estructura/`
- **Actividad 03:** `https://owwld.github.io/portafolio/03_selector_clase/`
- **Actividad 04:** `https://owwld.github.io/portafolio/04_SelectorId/`

> **Nota:** Cada carpeta debe contener un archivo `index.html` para cargarse automáticamente.
